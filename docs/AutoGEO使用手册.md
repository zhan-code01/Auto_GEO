## 1. 快速开始

### 1.1 登录与注册

1. 打开 AutoGEO 地址，首次使用点击「注册」，填写用户名、邮箱与密码完成注册（首个注册用户默认为管理员）。
2. 注册后使用账号密码「登录」，进入首页。

### 1.2 下载客户端（重要，发布功能的前置条件）

平台通过浏览器自动化完成「账号授权」和「文章发布」。在非桌面端使用时，需要先下载桌面客户端：

- 在左侧导航栏底部点击「**下载客户端**」，下载并安装 AutoGEO 桌面端（Electron 应用）。
- 后续「账号扫码绑定」「一键检测账号」「本地客户端发布」都依赖这个客户端在本机运行。

### 1.3 整体使用流程（业务闭环）

一个完整的 GEO 营销闭环，通常按以下顺序操作：

```
① 建客户 → ② 建 GEO 项目 → ③ 建知识库（上传企业资料）
    → ④ 生成文章 → ⑤ 绑定平台账号 → ⑥ 发布文章
    → ⑦ 监控 AI 收录 → ⑧ 查看数据报表 →（可选）⑨ 智能建站
```

各步骤分别对应本手册第 5、6、7、8、4 章。

## 2. 首页

首页是登录后的默认页面，相当于一个「内容增长作战台」，把全平台关键数据汇总到一屏，并引导你按正确顺序完成 GEO 营销全流程。

**页面包含以下区块**：

| 区块 | 内容与用途 |
| --- | --- |
| 顶部 Hero 区 | 两个高频快捷入口「生成文章」「发布任务」，右侧显示「今日发布」数量，一眼看到今天的产出 |
| 统计卡片（7 张） | 客户总数、知识库文件、生成文章、授权账号、发布任务、已收录、今日发布，点击任意卡片跳到对应模块 |
| 业务流程卡片（12 步） | 把「客户管理 → 知识库 → 智能建站 → 智能文章生成 → 文章管理 → 账号管理 → 发布任务 → 平台发布监控 → 收录监控 → 数据报表 → 定时任务 → 系统设置」串成一条线，点击任意一步直达对应页面 |
| 待办提醒 | 真实统计的待处理项：待发布文章数、账号待授权数，点击直接去处理 |
| 快速操作 | 新建客户 / 添加账号 / 生成文章 / 平台发布监控 四个常用入口 |
| 最近活动 | 最近一次成功发布的记录（类型、标题、平台、状态、时间） |

**新手第一次登录，建议按这个顺序走**：

1. 先看「业务流程卡片」，理解整条链路；
2. 从「快速操作」点「新建客户」，先把你的第一个客户建起来；
3. 按第 5 章到第 8 章的顺序，逐步把「项目、知识库、文章、账号、发布」补齐；
4. 每次登录先扫一眼「待办提醒」，把待发布、待授权的事处理掉。

> 首页数据全部是真实统计，点击即可跳转；本页无需任何配置。

## 3. 后台智能体

「后台智能体」是一个**对话式 AI 助手**：你不用在页面之间来回切换，直接用一句自然语言，就能让它替你完成「建客户 → 建项目 → 规划问题 → 生成文章 → 绑账号 → 审核发布」的一整套操作。

**界面构成**：

- 左侧**会话列表**：点「新建对话」开启新会话；每条会话可重命名 / 归档 / 删除，方便按客户或主题管理。
- 下方**快捷按钮**：建客户、建项目、上传资料、绑账号、生成并发布、查进度——点击即可直接触发对应操作，不用打字。
- 输入框：上限 1000 字，Enter 发送、Shift+Enter 换行；可直接粘贴或上传附件（PDF/Word/TXT/MD，单文件 ≤10MB，上传后进入知识库）。

**按场景的用法示例**：

| 你想做什么 | 可以这样说 |
| --- | --- |
| 建客户 | 「新建一个客户，公司叫『极速物流』，行业是物流运输」 |
| 上传资料 | 「帮我把这份公司介绍上传到『极速物流』的知识库」 |
| 生成文章 | 「帮极速物流写 5 篇关于『跨境电商物流』的文章」 |
| 绑定账号 | 「我要绑定知乎账号」 |
| 发布文章 | 「把文章 12 发布到知乎」 |
| 查进度 | 「我最近有哪些文章发布失败了？」 |

**助手会怎么回应**：以流式文字回复，并可能在对话里直接给出**可点击的卡片/按钮**——例如生成完文章会给你「文章卡片」（带「去发布」「复制正文」按钮），绑账号会弹出「添加账号」授权窗，让你在对话里就把事情办完。首次使用还有「新手引导 7 步卡」，可跳过。

**使用技巧**：

- 说得越具体越好：带公司名、数量、平台、关键词，AI 越能一次做对。
- 复杂任务它会边做边汇报，耐心等它完成（生成文章是后台异步任务，需轮询完成后才继续）。
- 如果回复「暂时无法处理」，通常是服务端未配置 AI 模型密钥，联系管理员即可。

## 4. 智能建站

### 4.1 模块简介

智能建站用于**快速生成一个企业官网（单页静态网站）**，无需写代码、无需设计功底。你只需要把公司信息填进去，系统就会自动排版成一个像样的官网。

操作方式是「**可视化编辑**」：左侧填表、右侧实时预览，所见即所得——把公司介绍、服务、案例、联系方式等内容填进去即可。

生成后的网站是一组静态文件（HTML/CSS/JS），可以**部署到你自己的服务器或对象存储**，最终通过你自己的域名访问。整个「建站 → 部署 → 上线」过程见 4.2 与 4.3。

### 4.2 可视化编辑建站

进入「智能建站」，界面分左右两栏：左栏是**内容编辑表单**（按区块折叠），右栏是**实时预览**，你改一个字右边立刻变。

**第 1 步：选择模板**

在顶部选择页面风格（商务风 `corporate` / 极简风 `cowboy`），点击即可切换预览，选一个顺眼的即可，之后所有内容都能改。

**第 2 步：逐区块填写内容**

下面用一个假想的「极速物流」公司做例子，说明每个区块该填什么：

| 区块 | 字段 | 填什么（以「极速物流」为例） |
| --- | --- | --- |
| 基本信息 | 公司全称、品牌主色、强调色 | 「极速物流有限公司」；主色选深蓝，强调色选橙色 |
| 首屏 Hero | 标签、标语、描述、背景图 | 标签「跨境物流」；标语「全球次日达」；描述一句话讲清主营业务；背景图放一张仓库/货机图 |
| 数据亮点 | 数值、单位、说明 | 如「500 + 员工」「10万 + 日处理包裹」 |
| 服务/解决方案 | 图标、标题、描述 | 「航空速运 / 海外仓 / 报关清关」等核心业务 |
| 关于我们 | 标题、简介、核心优势、配图 | 公司成立背景、为什么选我们、优势列表 |
| 常见问题 | 问题、回答 | 「运费怎么算？」「几天能到？」等客户常问问题 |
| 客户案例 | 封面、行业标签、标题、描述 | 如「某电商大促 0 爆仓」的案例 |
| 联系我们 | 地址、电话、邮箱 | 真实的联系方式，客户会从这里联系你 |

**填写技巧**：

- 标语和描述要「一句话讲清你是做什么的」，这是访客第一眼看到的内容。
- 数据亮点用真实、可信的数字，越具体越有说服力。
- 客户案例优先放「有结果」的（如节省多少成本、缩短多少时效）。

**第 3 步：生成预览**

填写完成后点击「**生成预览**」按钮，右侧渲染出完整页面。从头到尾滚动检查一遍，确认无误后进入 4.3 部署上线。

### 4.3 部署上线

部署是让网站**能在公网通过你自己的域名打开**的关键一步。本产品支持两种发布方式：**远程服务器（SFTP）** 和 **云对象存储（OSS/S3）**。下面先讲最常用的 SFTP 方式，并给出一套「从零到上线」的完整操作流程。

#### 前置准备（只需做一次）

如果想让别人通过「你的域名」访问网站，需要自己先准备好以下四样东西：

1. **购买域名**：在阿里云、腾讯云、华为云等平台购买，例如 `example.com`。
2. **购买云服务器**：购买一台 Linux 云服务器（如阿里云 ECS、腾讯云 CVM），记下服务器的**公网 IP**（形如 `1.2.3.4`）。
3. **DNS 解析（把域名指到服务器）**：在域名服务商的控制台添加一条 **A 记录**：
   - 主机记录：`@`（让 `example.com` 生效）或 `www`（让 `www.example.com` 生效）；
   - 记录值：服务器的**公网 IP**；
   - 保存后等待生效（通常几分钟到几小时），之后访问该域名就会指向你的服务器。
4. **在服务器上安装 Web 服务**：推荐安装 Nginx（或宝塔面板一键安装），确认其网站根目录（Nginx 默认为 `/var/www/html`，宝塔一般为 `/www/wwwroot/你的站点`）。

#### 方式 A：远程服务器（SFTP，推荐）

点击「**立即部署**」，在弹出的「发布上线配置」对话框中选择「**远程服务器 (SFTP)**」标签，按下面字段填写：

| 字段 | 填写内容 | 示例 |
| --- | --- | --- |
| 主机 IP | 云服务器公网 IP | `1.2.3.4` |
| SSH 端口 | 通常保持默认 | `22` |
| 用户名 | 登录服务器的账号 | `root` 或 `ubuntu` |
| 认证方式 | 二选一：密码 / PEM 私钥 | 密码 |
| 密码 | 服务器登录密码（选密码时） | 你的密码 |
| PEM 私钥 | 粘贴私钥全文（选私钥时） | `-----BEGIN ... PRIVATE KEY-----` |
| 私钥口令 | 私钥若有口令则填，否则留空 | 留空 |
| 上传路径 | 网站根目录的绝对路径 | `/var/www/html` |
| 访问域名 | 你绑定的域名，含协议 | `https://www.example.com` |
| 站点目录名 | 可选，留空自动生成 | 留空 |

点击「部署」后，系统会把网页文件上传到 `上传路径/<目录名>/` 下，并返回访问地址（形如 `https://www.example.com/<目录名>/index.html`）。用浏览器打开该地址即可看到你的网站。

> 小技巧：若希望网站直接挂在域名根目录（打开 `https://www.example.com` 就是首页），可在服务器 Nginx 里把站点 root 指向系统生成的目录名；或填写时自定义「站点目录名」，并让 Nginx root 与之对应。

#### 方式 B：云对象存储（OSS/S3）

适合没有服务器、只想用静态托管省钱的情况：

1. 在云平台开通对象存储（阿里云 OSS / 腾讯云 COS / AWS S3），创建 Bucket，**开启静态网站托管**并设为公共读。
2. 为 Bucket **绑定已备案的自定义域名**（重要：OSS 默认域名访问网页会被强制下载，必须绑自定义域名才能在线打开）。
3. 在对话框选择「云对象存储 (OSS/S3)」，填写：

| 字段 | 填写内容 |
| --- | --- |
| Endpoint | 区域级地址，如 `https://oss-cn-hangzhou.aliyuncs.com` |
| Bucket | 桶名称 |
| AccessKey / SecretKey | 云平台访问凭证 |
| 访问域名 | 绑定的自定义域名 |

点击部署后，访问返回的地址即可看到网站。

#### 完整案例：从零到上线（8 步）

以「极速物流」公司、域名 `jisu.example.com` 为例，走一遍完整流程：

1. **买域名**：在云平台购买 `example.com`。
2. **买服务器**：买一台 Linux 云服务器，记下公网 IP（如 `1.2.3.4`）。
3. **DNS 解析**：添加 A 记录，主机记录 `jisu`、记录值 `1.2.3.4`，让 `jisu.example.com` 指向服务器。
4. **装 Nginx**：在服务器安装 Nginx（或宝塔一键安装），确认根目录 `/var/www/html`。
5. **在 AutoGEO 里建站**：进「智能建站」，选模板、填好极速物流的内容、点「生成预览」。
6. **填部署参数**：点「立即部署」→ SFTP，填主机 IP `1.2.3.4`、用户名 `root`、密码、上传路径 `/var/www/html`、访问域名 `http://jisu.example.com`。
7. **点部署**：等待上传完成，系统返回访问地址。
8. **验收**：浏览器打开返回地址，确认网页显示正常；再在 Nginx 里把该站点目录设为 `jisu.example.com` 的 root，即可直接通过 `http://jisu.example.com` 打开首页。

> 以上步骤中，第 1–4 步是「自己准备环境」，只需做一次，之后多个网站都能复用；第 5–8 步是「在 AutoGEO 里建站上线」。

#### 部署常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 提示「无法连接远程服务器」 | IP/端口错、防火墙未放行 22 端口 | 检查主机 IP 与安全组放行 22 端口 |
| 提示「用户名/密码或私钥无效」 | 凭证错 | 核对用户名密码；私钥需为 PEM 格式 |
| 提示「目录没有写权限」 | 上传路径不可写 | 换有权限的目录，或给用户加写权限 |
| 已上传但打不开 | 域名解析未生效 / Nginx root 不对 | 等 DNS 生效，核对 Nginx root 与上传路径 |
| 对象存储打不开、直接下载 | 用了默认域名 | 绑定自定义域名并开启静态网站托管 |

## 5. 项目与知识库

这一分组包含客户、项目、知识库三类数据，是后面「生成文章」和「智能建站」的**数据底座**。先理解三者关系，操作会更顺：

```
客户（一家公司）
 ├── GEO 项目（围绕品牌+关键词做优化，一个客户可有多个项目）
 └── 知识库（存放该公司资料，供 AI 引用）
```

- **客户**：回答「谁」——你要服务的哪家企业。
- **GEO 项目**：回答「做什么」——围绕某品牌/关键词的优化目标。
- **知识库**：回答「靠什么写」——AI 生成文章/建站时引用的事实依据。

> 建议顺序：先建客户 → 再在该客户下建项目、传资料。这样所有文章和收录监控都能正确归属到这个客户，不会乱。

### 5.1 客户管理

**用途**：管理服务对象（企业客户）的基础档案，作为项目、知识库、文章的归属主体。

**字段**：公司名称（必填）、所属行业（必填，可自定义）、所在地（必填）、公司官网（必填）、联系人、联系电话、邮箱、状态（活跃/停用）。

**操作**：

- 顶部统计卡展示总客户 / 活跃 / 停用 / 行业数；工具栏支持按公司名称搜索、按状态/行业筛选。
- 点击「新建客户」填表保存；列表每行提供「查看项目 / 上传资料 / 编辑 / 删除」。
  - **查看项目**：弹窗列出该客户下的 GEO 项目，可在此新建/编辑/删除项目。
  - **上传资料**：选择资料分类（公司资料/产品文档/行业报告/技术文档/其他），拖拽上传（最多 5 个，支持 `.pdf` `.doc` `.docx` `.txt` `.md`，单个 ≤10MB），上传后可能自动提取并回填客户信息（待确认保存）。
- 客户可下挂多个项目和知识库，知识库资料会用于文章生成与智能建站。

### 5.2 GEO 项目管理

**用途**：围绕「品牌/公司 + 关键词」建立一个 GEO 优化项目，是关键词、文章与收录监控的载体。

**创建/编辑字段**：项目名称（必填）、公司名称（必填，下拉选择客户）、领域关键词（必填，用于 AI 蒸馏生成用户提问句）、所属行业（可自定义）、项目描述。

**「领域关键词」填什么**：填你的品牌/产品所在领域的核心词，例如物流公司可填「跨境物流」「海外仓」「国际快递」。系统会围绕这些词，用 AI 生成用户的搜索提问句（如「跨境物流哪家快？」），后续文章就是围绕这些提问来写的。

**操作**：

- 点击「新建项目」填表；项目卡片展示项目名、所属客户、文章数、问题数、行业，右上角菜单可编辑/删除项目（删除会连带删除关键词和文章）。
- 点击卡片进入**关键词管理**页（管理该项目的领域关键词/搜索问题）。
- 收录的「打基线」不在本页，在「收录监控」页面进行（见 8.1）。

**前置**：需先在「客户管理」创建客户。

### 5.3 知识库管理

**用途**：上传企业资料（公司介绍、产品文档等），作为 AI 生成文章、智能建站时的「企业事实来源」，避免 AI 胡编。

**界面要点**：页面头部显示「RAGFlow 已连接/未连接」状态；知识库卡片显示文件数与分块数；点击卡片打开文档抽屉，可搜索、上传、预览、重新解析、删除文档。

**操作**：

1. 点击「新建知识库」，填写名称，并可关联到某个客户。
2. 在知识库中「上传文档」，支持格式：`.pdf` `.doc` `.docx` `.txt` `.md` `.ppt` `.pptx` `.xls` `.xlsx`；可勾选「上传后自动解析」。
3. 文档解析状态分「等待中/解析中/已完成/已取消/失败」；上传后系统同步到 RAGFlow 知识库，供文章生成与智能建站检索使用（按关键词检索相关片段作为事实依据）。

> 前置：需后端已配置 RAGFlow 连接（`RAGFLOW_BASE_URL`/`RAGFLOW_API_KEY`）；未连接时上传会失败，请联系管理员。

> **上传什么资料效果最好**：公司简介、产品/服务介绍、案例、资质证书、常见问题、联系方式等。资料越全，AI 写出来的文章和网页越贴切、越不像胡编。反之资料缺失，AI 只能靠通用知识补写，可能与公司实际不符。

## 6. 内容生产

这一分组负责「把知识库里的企业资料，变成一篇篇能发的文章」。

**核心思路：从「用户会搜什么」出发写文章。** 传统营销是「我想写什么就写什么」；GEO 做法是先列出用户在搜索/问 AI 时真正关心的问题（搜索问题池），再围绕每个问题写一篇能回答它的文章——这样当用户问 AI「某某问题」时，你的品牌/文章更容易被 AI 引用和推荐。

- 「智能文章生成」：批量规划问题 + 批量成文。
- 「文章管理」：审校、编辑与发布前的最后一道关卡。

### 6.1 智能文章生成

**用途**：面向「客户 + 项目」批量生成一批 GEO 文章，采用「规划问题 → 生成文章 → 审核发布」三步工作流，从「搜索问题池」出发覆盖多个用户搜索意图。

**典型流程**：

1. 选择所属公司、关联项目（选公司后启用；若该公司尚无项目会提示先创建）。
2. 设置「问题数量」（1–30，默认 10），点击「生成用户问题」，系统用 AI 生成该项目的用户搜索问题池（进度条实时刷新）。
3. 问题池表格展示：用户问题、问题类型（推荐/选型/方案/比较/场景/实施/风险等）、文章状态、创建时间；可筛选「未生成文章/已生成文章」。
4. 勾选要写文章的问题，点击「生成 N 篇文章」，系统批量调用 AI 产出文章（默认存入「草稿」），进度条实时显示。
5. 完成后点「前往文章管理」查看与发布。

> 小知识：问题池里的每道题会带一个「问题类型」（推荐/选型/方案/比较/场景/实施/风险等），代表用户不同的决策阶段。覆盖多种类型，能更全面地截获处于不同阶段的潜在客户。

### 6.2 文章管理

**用途**：统一查看和管理所有已生成的文章，是发布前的最后一道关卡。

**功能**：

- **筛选**：按项目分类、按状态（待分发 / 已发布 / 失败）过滤。
- **列表列**：标题（含项目名）、状态、阅读数、创建时间、操作（预览 / 编辑 / 去发布或重新发布）。
- **单篇发布**：点击「去发布」弹出发布对话框，选择发布方式（立即发布/定时发布）、发布平台、发布账号（按平台过滤已授权账号）、发布时间（定时必选）。
- **编辑**：编辑页为「标题 + 富文本正文」，右侧列出「已连接平台账号」，可勾选多个账号「一键发布到平台」。
- **批量发布 / 批量删除**：勾选多篇后点「批量发布」进入批量发布向导，或「批量删除」。
- **质检**：对文章做 AI 质量评估（内容质量、事实风险、平台合规风险、重复度）。
- **收录检测**：对已发布文章检查其被搜索引擎收录的状态。

**文章状态说明**：

| 状态 | 含义 |
| --- | --- |
| 待分发 | 已生成、待发布（涵盖草稿 / 生成中 / 已定时 / 发布中等细分） |
| 已发布 | 已成功发布到平台 |
| 失败 | 生成或发布失败，可查看原因并重试 |

### 6.3 GEO 文章生成

> 该入口在侧边栏默认隐藏，页面顶部标注「已废弃，请转到智能文章生成模块」，但仍可作旧版单篇/整项目生成使用。

**表单字段**：选择项目（必填）、选择搜索问题（必填）、发布平台（多选）、发布策略（仅生成草稿 / 生成后立即发布 / 定时发布）、发布时间（定时时选）。

**操作**：点「生成文章」生成单篇；点「生成全部文章」把整项目按队列逐个生成（可轮询进度）。列表操作支持预览/编辑（标题+富文本）、质检（刷新评分）、去发布（发布对话框内置快捷时间：30 分钟/1 小时/2 小时/明早 9 点/明晚 8 点）。

### 6.4 批量发布

> 该入口默认隐藏，用于把一批文章一次性发布到多个账号/平台。执行依赖桌面客户端的本地发布引擎。

**操作**（四步向导）：① 勾选多篇文章 → ② 勾选目标平台并多选账号（可一键应用到全部）→ ③ 确认发布时机 → ④ 进入进度监控查看执行结果。

## 7. 发布管理

这一分组负责「把写好的文章发到各大内容平台」，包含账号、发布任务与实时监控三块：

- **账号管理**：先把你各平台的账号登录态绑定进来（扫码授权）。
- **发布任务管理**：选文章 + 选账号，一键或定时批量发布。
- **平台发布监控**：实时看发布进度与结果。

> 为什么发布前要「扫码绑账号」？因为系统用浏览器自动化替你在各平台发文，必须先用你自己的账号在真实浏览器里登录一次、把登录态加密保存下来，之后才能自动操作。

### 7.1 账号管理

**用途**：绑定各内容平台的账号（知乎、百家号、头条号、搜狐、抖音、快手、小红书、B站、微博、微信公众号、网易号、企鹅号、豆瓣、简书、掘金、CSDN、贴吧等），发布时使用这些账号的登录态。

**界面**：顶部工具栏含「筛选平台」「状态筛选」「一键检测所有」「添加账号」；账号以卡片网格展示（平台图标 + 状态圆点 + 账号名 + @用户名 + 平台名），卡片操作有「去授权」「编辑」「删除」（贴吧账号另有「目标吧」）。

**绑定流程（扫码授权）**：

1. 确保已安装并打开 AutoGEO 桌面客户端（见 1.2）；网页端点「添加账号」会提示需用客户端。
2. 在客户端点「添加账号」，选择平台、填备注名（如「知乎大号」）。
3. 点「启动浏览器授权」，本机 Chrome 打开该平台登录页。
4. 在窗口中**扫码或输入密码登录**你的平台账号。
5. 点「已完成登录」，后端提取登录态（Cookie）加密保存，提示「授权成功」。
6. 贴吧账号绑定后需配置「目标吧」（可多选，第一个为默认发布吧）。

> 绑定前准备：确保手头有各平台账号的登录方式（手机扫码或账号密码），并已下载、打开桌面客户端。

**账号状态**：

| 状态 | 含义 |
| --- | --- |
| 登录有效（1） | 授权可用 |
| 授权过期（-1） | 登录态失效，需「去授权」重新绑定 |
| 禁用/未授权（0） | 未授权或已禁用 |

**一键检测**：点击「一键检测所有」，确认后进入进度对话框（逐账号显示有效/失效/无法确认）。桌面端用本地无头浏览器逐账号验证并回写状态；网页端走服务端轻量检测 + WebSocket 进度。

> 说明：账号的健康度、最后检测时间、分组/标签等字段暂未在页面展示（后端预留）。安全提示：平台登录态会加密存储，仅用于本产品自动发布；传输建议走 HTTPS（见附录 A）。

### 7.2 发布任务管理

**用途**：把文章批量发布到多平台，支持立即/定时执行（由桌面客户端本地执行）。

**创建表单字段**：

- 任务名称（必填）、任务描述
- 选择文章（必填，多选下拉，标注已发布/未发布）
- 选择账号（必填，树形结构：勾选平台=全选该平台账号，可展开逐账号勾选）
- 执行类型：立即执行 / 定时执行（卡片单选）
- 后台运行开关（开启后可在「平台发布监控」看进度）
- 执行时间（选定时时出现，不可选过去时间）

**任务卡片**：显示名称、状态标签（待执行/执行中/已完成/失败/已取消）、执行类型（定时/间隔）、平台标签、文章数/账号数/总任务数/已完成/失败、进度条、错误信息；操作有「启动 / 取消 / 重试 / 详情 / 删除」。点「详情」可查看「基本信息」+「子任务记录」表格（文章/账号/平台/状态/查看/错误）。

**操作**：点击「创建任务」填表保存；创建后系统自动尝试启动本地客户端发布引擎执行。

**前置**：账号已授权且当前本机已登录该平台（未满足的平台整组置灰并提示「未在本机登录」）；至少 1 篇文章。

### 7.3 平台发布监控

**用途**：实时监控发布任务的执行过程与结果（只读页面）。

**界面**：

- 顶部 4 张统计卡：总任务数 / 已完成 / 执行中 / 失败，附「刷新」。
- 按平台分组卡片：平台色标、完成数/总数、失败数、进度条、异常态标红。
- 每条任务行：文章名、账号名、状态标签（发布中/成功/失败/等待中）、「重试」（失败时）、「查看」（有平台链接时新窗口打开）、错误信息。
- 数据通过 WebSocket 实时推送自动刷新。

**用途场景**：发布失败时在此定位问题（如账号过期、平台风控等），并对失败项一键重试。

## 8. 数据与监控

这一分组回答一个关键问题：**「你的品牌，有没有被 AI 搜索收录、推荐？」**

> 背景：越来越多人用 AI（豆包、通义千问、DeepSeek 等）提问，而不是用传统搜索引擎。GEO（生成式引擎优化）就是让你的品牌在这些 AI 的回答里「被提到、被推荐」。本分组就是用来检测和量化这个效果的。

### 8.1 收录监控

**用途**：把品牌关键词问题跑到豆包 / 通义千问 / DeepSeek，监控 AI 收录情况并做「使用前后」对比诊断。

**核心概念**：

- **基线（baseline）**：对某公司先打一次「使用服务前」的收录基线，作为对比起点。
- **复测（ongoing）**：系统每晚自动复测，记录收录变化。

**操作**：

1. 顶部选择「公司」，查看各平台授权状态（绿=已授权/红=未授权），点「管理授权」可去授权/重新授权。
2. 确认「测评问题集」已有基线或待建立（可「预览问题」），选择测评平台与授权账户。
3. 点「生成基线（N）」建立初始快照；已有基线后点「继续测评」或「执行使用后测试（N）」。运行中可暂停/取消，平台要求人工验证时按提示操作后「重新检测」。
4. 结果以 **GEO 四指标**展示，并支持点记录查看「AI 回答原文」。

**四指标通俗解释**：

| 指标 | 大白话 |
| --- | --- |
| AI 可见度 | AI 回答里提到你品牌的综合程度（覆盖 + 排名 + 情感的综合分） |
| 出现覆盖率 | 你被 AI 提及的提问占比（100 个问题里有多少个提到了你） |
| 推荐排名 | 被提及时的位置与推荐强度（越靠前、越推荐分越高） |
| 情感分 | AI 提到你时是夸还是贬（正/负/中性） |

**前置依赖**：先建客户 → 建项目 → 智能文章生成问题集 → 平台授权（客户端本机浏览器），之后才能打基线/复测；网页端会提示需桌面客户端。

### 8.2 数据报表

**用途**：把收录检测、发布等数据汇总成图表报表，衡量 GEO 效果。

**界面与报表**：

- 顶部筛选：项目下拉、时间范围（近 7 天/近 30 天）、平台单选（全平台/DeepSeek/豆包/通义千问）、「刷新」、「执行收录检测」（需先选项目，完成后自动刷新）。
- **数据总览 4 卡**：文章生成数（普通/GEO）、发布成功率、关键词命中率、公司名命中率。
- **收录诊断·使用前后对比**：三栏卡片——使用前基线（建立时间/检测次数/平均提及）、变化幅度（关键词/公司名提升百分比 + 显著提升/下降判定）、使用后当前；附平台对比小表。点「生成基线快照/重新生成基线」可重建。
- **AI 平台对比分析**：各平台命中率柱状图。
- **项目影响力排行榜**：排名/品牌项目/公司/内容声量/AI 提及率/品牌关联度。
- 「查看检测记录」跳转收录监控页。

**怎么看「使用前后对比」诊断**：中间「变化幅度」栏给出关键词命中率 / 公司名命中率相比基线提升了多少个百分点，并标注「显著提升 / 下降」。提升明显 = GEO 服务起效。

**前置**：已建项目并跑过收录检测；诊断需先有基线。

### 8.3 定时任务

**用途**：查看和管理系统内置的自动化任务，通常无需改动。

**内置任务**（默认已启用）：

| 任务 | 作用 | 默认频率 |
| --- | --- | --- |
| 文章自动发布引擎 | 扫描到点的定时发布文章并执行 | 每分钟 |
| 全网收录实时监测 | 检测已发布文章收录状态 | 每 5 分钟 |
| AI 收录定期复测 | 复测项目关键词在 AI 搜索的收录 | 每天凌晨 |
| Excel 批量生成恢复 | 恢复卡住的批量生成任务 | 每 3 分钟 |
| 自动发布任务调度 | 调度到点的定时/间隔发布任务 | 每分钟 |

**操作**：可查看各任务状态、开关任务（即时生效）、点「修改频率」（模式：按间隔 1–1440 分钟 / 按时间 HH:mm）、点「立即执行」手动触发。一般建议保持默认频率。

## 9. 系统设置

「系统设置」页主要提供**运行状态监控与桌面端偏好设置**：

- **服务连接状态**：健康检查（整体状态 + 数据库 PostgreSQL 连接状态 + RAGFlow 状态），失败时页面内红字提示原因。

- **关于**：产品版本信息。

## 附录 A：部署与安全注意事项

1. **HTTPS**：正式对外使用时，请为域名配置 SSL 证书并启用 HTTPS，账号登录态与用户数据应加密传输。
2. **域名备案**：使用中国大陆服务器或对象存储绑定域名时，需按工信部要求完成 ICP 备案。
3. **服务器安全组**：SFTP 部署需放行 22 端口；对外只暴露必要的 80/443 端口。
4. **账号安全**：平台账号登录态属于敏感信息，请勿把导出数据、会话文件或数据库备份提交到公开代码仓库。
5. **数据库**：生产环境务必配置独立的数据库地址与加密密钥（`DATABASE_URL`、`AUTO_GEO_ENCRYPTION_KEY`、`JWT_SECRET_KEY`）。

## 附录 B：常见问题 FAQ

**Q1：发布文章时报「账号授权过期」？**
进入「账号管理」找到该账号，点击「去授权」重新扫码绑定即可。

**Q2：点了「发布」但没反应？**
先确认已下载并运行桌面客户端（左侧底部「下载客户端」），发布多走本地客户端模式。

**Q3：网站部署成功但打不开？**
按「4.3 部署常见问题」排查：DNS 是否生效、Nginx root 是否与上传路径一致、防火墙是否放行。

**Q4：AI 生成的内容不符合公司实际情况？**
请先在「知识库管理」上传足够的企业资料，AI 会优先依据知识库内容生成。

**Q5：收录监控为什么看不到变化？**
收录变化是日/周级变化，需先打基线、并等待系统按计划复测后，到「数据报表 → 诊断」查看前后对比。
